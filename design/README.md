# Design references

- `*.dc.html`: mockups exported from the design canvas. They don't render standalone. Read their inline styles for exact colors, spacing and copy.
  - Current style (direction E, "Little Characters"): `Home.dc.html`, `Main.dc.html` (Discover), and column E of `Visual-Directions.dc.html`.
  - Older style (layout and flow reference only): `Say-It-Better`, `Fridge-Chef`, `Bedtime-Stories`, `Skill-Detail`, `Form-Filler`, `Paperwork-Filer`, `Tidy-My-Mac`.
- `characters/<skill>.svg`: full app-icon tile (colored rounded square + character).
- `characters/<skill>-glyph.svg`: character only, on transparent, for use on custom backgrounds.
